Core CICFM Contract

CICFM changes the model from predicting values directly to predicting a velocity in value space. The original target value becomes the data endpoint z1. A sampled source value becomes z0. A sampled time t chooses an interpolated value zt between them. 

z1 = targets
z0 ~ Uniform(0, 1)
t  ~ Uniform(0, 1), shape [B, N, 1]

zt = (1 - t) * z0 + t * z1
target_velocity = z1 - z0
Important: for the first linear path, target_velocity is independent of t. That is expected.

Tensor Shapes

Name Shape Meaning
features [B, N, D + 2 * D * F] Raw coordinates plus Fourier features.
z0 [B, N, C] Source/noise value.
z1 [B, N, C] Target/data value, equal to targets.
t [B, N, 1] Per-point scalar time.
zt [B, N, C] Interpolated value at time t.
target_velocity [B, N, C] Regression target for velocity prediction.
cicfm_input [B, N, D + 2 * D * F + C + 1] Concatenated model input in CICFM mode.

Model Input Assembly

CICFM mode keeps the same hidden MLP architecture as MSE mode, but the input dimension changes because the model now receives embedded coordinates, the interpolated value, and time. 

cicfm_input = concat(features, zt, t)

For each point:

cicfm_input[b, n] = [
  features[b, n, :],
  zt[b, n, :],
  t[b, n, 0]
]
Configuration Feature dim CICFM input dim Output dim
D = 2, C = 3, F = 8 34 38 3
D = 2, C = 3, F = 16 66 70 3

Forward and Loss Semantics

MSEDirect Value Prediction

prediction = mlp(features)
loss = mean((prediction - targets)^2)

CICFMVelocity Prediction

predicted_velocity = mlp(cicfm_input)
loss = mean((predicted_velocity - target_velocity)^2)
Do not compare predicted_velocity directly to targets. In CICFM mode the model output means velocity, not RGB/value prediction.

Deterministic Smoke Test

Before random sampling is enabled, the contract defines a deterministic assembly test: 

z0 = zeros_like(targets)
t = 0.5
z1 = targets

zt = 0.5 * targets
target_velocity = targets
cicfm_input = concat(features, 0.5 * targets, 0.5)

Expected checks:

max_abs(zt - 0.5 * targets) < 1e-6
max_abs(target_velocity - targets) < 1e-6
cicfm_input.shape[2] == feature_dim + C + 1

What Was Intentionally Not Implemented

  • No optimizer or parameter initialization changes.
  • No manual backward pass yet.
  • No ODE sampling after training.
  • No separate context tensor.
  • No sinusoidal time embedding.
  • No CUDA kernel changes.
  • No adaptive coordinate sampling.

Definition of Done

  1. CICFM tensors have exact names and shapes.
  2. z0 is frozen as Uniform(0, 1) for the first version.
  3. t is frozen as per-point scalar time with shape [B, N, 1].
  4. zt = (1 - t) * z0 + t * z1.
  5. target_velocity = z1 - z0.
  6. cicfm_input = concat(features, zt, t).
  7. Shape checks and deterministic smoke tests are specified.
