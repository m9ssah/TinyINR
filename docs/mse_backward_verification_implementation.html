Backward Scope

Day 4 stays focused on the direct MSE baseline. The model receives embedded coordinate features, predicts target values, computes mean squared error, and propagates gradients backward through the MLP. 

features -> MLP -> prediction
prediction + targets -> MSE loss
MSE gradient -> output layer
manual backward -> all layer gradients
CICFM scaffolding exists, but it should not be used to debug backward propagation. The MSE path must pass gradient checks and tiny overfit checks first.

MSE Loss and Output Gradient

The contract uses mean squared error over every flattened point and output channel. 

R = B * N
count = R * C
loss = (1 / count) * sum_r sum_c (Y[r, c] - T[r, c])^2

dY[r, c] = 2 * (Y[r, c] - T[r, c]) / count

Hand-check example:

Y = [[1, 2, 3]]
T = [[0, 2, 4]]

loss = 0.6666667
dY = [[0.6666667, 0, -0.6666667]]

Linear Backward

Weights are stored as [out_dim, in_dim], so the backward formulas are: 

Y = X * W^T + b

dW[o, i] = sum_r dY[r, o] * X[r, i]
db[o]    = sum_r dY[r, o]
dX[r, i] = sum_o dY[r, o] * W[o, i]
Tensor Shape
dW [out_dim, in_dim]
db [out_dim]
dX [R, in_dim]

SiLU Backward

SiLU is applied after the first three linear layers only. Backward must use cached pre-activations. 

silu(x) = x * sigmoid(x)
d_silu(x) = sigmoid(x) + x * sigmoid(x) * (1 - sigmoid(x))

dZ = dA * d_silu(Z)
At x = 0, d_silu(0) = 0.5. This is a simple sanity check for the derivative implementation.

Full MLP Backward Order

dY = 2 * (Y - T) / (R * C)

dW3, db3, dA2 = linear_backward(dY, A2, W3)

dZ2 = dA2 * d_silu(Z2)
dW2, db2, dA1 = linear_backward(dZ2, A1, W2)

dZ1 = dA1 * d_silu(Z1)
dW1, db1, dA0 = linear_backward(dZ1, A0, W1)

dZ0 = dA0 * d_silu(Z0)
dW0, db0, dX = linear_backward(dZ0, X, W0)

Verification Gates

Gate 1MSE scalar value

Verify a hand-computable loss before touching model layers.

Gate 2MSE output gradient

Verify dY = 2 * (Y - T) / count.

Gate 3SiLU derivative

Compare analytic derivative against finite differences.

Gate 4Linear backward

Verify dW, db, and dX.

Gate 5Full MLP finite differences

Check selected parameters in a tiny model.

Gate 6Tiny fixed-batch training

Confirm loss decreases on the deterministic synthetic target.

Gradient Check Protocol

numeric_grad(theta_i) =
    (loss(theta_i + eps) - loss(theta_i - eps)) / (2 * eps)

eps = 1e-3
absolute_error < 1e-3
relative_error < 1e-2

Recommended tiny model:

input_dim = 5
hidden_width = 4
output_dim = 3
R = 2

Tiny Overfit Check

The first training run should use the deterministic synthetic target from Day 2: 

y_r = 0.5 + 0.5 * x
y_g = 0.5 + 0.5 * y
y_b = 0.5 + 0.25 * sin(pi * x) + 0.25 * cos(pi * y)

Initial pass criteria:

loss_after_100_steps < loss_at_step_0
loss is finite
all gradients are finite
all parameter updates are finite
