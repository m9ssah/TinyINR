MSE and CICFM Model/Loss Implementation

This page explains the CPU trainable baseline added on branch mse-cicfm: the four-layer SiLU MLP, shared MSE loss, CICFM batch assembly, manual backward pass, SGD smoke training, and validation tests.

Model
4 linear layers

Three SiLU hidden layers and an identity output.

Loss Modes
MSE + CICFM

Both modes reuse the same MSE reduction.

Validation
6 CPU tests

Forward, loss, CICFM, backward, overfit, and embedding.

Implementation Files

File What It Does
include/model/mlp.h, src/model/mlp.cpp Defines MlpConfig, four LinearLayer parameters, deterministic initialization, SiLU, forward caching, manual backward, zeroing gradients, and SGD updates.
include/training/loss.h, src/training/loss.cpp Implements shared MSE scalar loss, output gradient, loss+gradient helper, and dimension helpers for MSE and CICFM input sizes.
include/training/cicfm.h, src/training/cicfm.cpp Implements CICFM source/time assembly, deterministic CICFM debug batches, zt, target_velocity, and concat(features, zt, t).
include/training/train_debug.h, src/training/train_debug.cpp Adds finite-value and magnitude statistics for tensors, parameters, and gradients.
include/training/train_step.h, src/training/train_step.cpp Adds the LossMode-driven train-step interface. This is now the single dispatch point for selecting MSE features/targets or CICFM concat(features, zt, t)/target_velocity.
CMakeLists.txt Builds the new CPU model/loss modules and tests. CUDA targets are now optional so CPU tests can run on machines without nvcc.

The baseline helper uses width 256, but tests can create smaller models so finite-difference and overfit checks stay fast.

MSE Path

features -> mlpForward -> prediction
loss = mean((prediction - targets)^2)
d_prediction = 2 * (prediction - targets) / count
mlpBackward(model, cache, d_prediction)
sgdStep(model, learning_rate)

CICFM Path

z1 = targets
z0 ~ Uniform(0, 1)
t ~ Uniform(0, 1)
zt = (1 - t) * z0 + t * z1
target_velocity = z1 - z0
cicfm_input = concat(features, zt, t)
predicted_velocity = mlpForward(model, cicfm_input)
loss = mean((predicted_velocity - target_velocity)^2)
CICFM changes the model input and the loss target, but it reuses the same MLP forward, MSE reduction, MSE output gradient, backward pass, and SGD update.

LossMode Train Step

The branch now includes a unified trainStep function. The caller passes LossMode::MSE or LossMode::CICFM, and the train step validates dimensions, selects the model input, selects the loss target, runs forward/loss/ backward, applies SGD, and returns debug tensors and stats. 

MSE trainStep:
  model_input = features
  loss_target = targets

CICFM trainStep:
  cicfm = makeCicfmBatch(features, targets, z0, t)
  model_input = cicfm.input
  loss_target = cicfm.target_velocity

The CICFM dispatch test uses seeded random z0 and t so it proves the loss target is target_velocity = z1 - z0, not raw targets.

Tests Added

Test Purpose
test_mlp_forward Checks SiLU values, output shape, cache shape, and deterministic initialization.
test_loss Checks hand-computed MSE loss, output gradient, and MSE/CICFM dimensions.
test_cicfm Checks deterministic zt, target_velocity, input dimension, and velocity-target loss.
test_mlp_backward Checks finite gradients and finite-difference agreement for selected parameters.
test_training_debug Checks MSE overfit loss decrease, CICFM deterministic overfit loss decrease, and finite random CICFM step.
test_train_step Checks LossMode dispatch, MSE/CICFM dimension rejection, and CICFM target-velocity selection.
test_full_size_baseline Checks real width-256 MSE and CICFM finite train steps with frozen F = 8 dimensions.
test_fourier_embedding_tensor Existing embedding contract test, rerun to protect the input feature path.
