Final Frozen Design

The trainable baseline has one MLP family. MSE and CICFM share the same hidden architecture, activation, output dimension, loss reduction, and backward formulas. They differ in input assembly and loss target.

MSE Formula

features = fourier_embedding(coordinates, F)
prediction = mlp(features)
loss = mean((prediction - targets)^2)
d_prediction = 2 * (prediction - targets) / (B * N * C)

CICFM Formula

z1 = targets
z0 ~ Uniform(0, 1)
t ~ Uniform(0, 1), shape [B, N, 1]
zt = (1 - t) * z0 + t * z1
target_velocity = z1 - z0
cicfm_input = concat(features, zt, t)
predicted_velocity = mlp(cicfm_input)
loss = mean((predicted_velocity - target_velocity)^2)
CICFM must not start until the MSE tiny overfit test passes and manual backward math is verified.

Correctness Gates

  1. MSE forward shapes pass.
  2. MSE loss and output gradient pass hand checks.
  3. MLP backward passes finite differences.
  4. MSE tiny overfit loss decreases.
  5. Deterministic CICFM assembly passes.
  6. CICFM loss target probe passes.
  7. CICFM deterministic backward gradients are finite.
  8. CICFM deterministic overfit loss decreases.
  9. Random CICFM remains finite.
  10. F = 16 passes the same shape and finite checks.
